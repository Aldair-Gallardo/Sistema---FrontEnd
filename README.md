# Sistema — FrontEnd

Repositorio del frontend de TECA, una tienda online con panel administrativo por roles.

El proyecto de Next.js vive dentro de la carpeta [`my-app`](my-app), no acá en la raíz. Toda la documentación real — qué hace la app, cómo instalarla, scripts, roles y solución de problemas — está en **[my-app/README.md](my-app/README.md)**.

Necesita el backend (`teca-backend`, FastAPI) corriendo aparte para que el login y las demás llamadas a la API funcionen.
