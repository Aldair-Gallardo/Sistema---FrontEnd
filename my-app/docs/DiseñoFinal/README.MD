# Diseño final de pantallas — TECA

Documento de diseño final de las interfaces de TECA, entregado como parte del proyecto final.

## Contenido

- `Diseño Final de Pantallas.pdf`: sistema visual (colores, tipografía, componentes), las pantallas finales del sistema —acceso, tienda, compra, cuenta del cliente y panel administrativo— y el cierre con la correspondencia entre lo diseñado y lo implementado.

Las decisiones de diseño se trabajaron primero en Miro antes de pasar a la implementación; el documento incluye una sección breve mostrando ese proceso.
